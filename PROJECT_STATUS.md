# ArDiRec project status

## Current release

**v0.2.0 Stable — published 3 November 2026.** Downloadable Windows and Linux packages are available from [GitHub Releases](https://github.com/masarray/ardirec/releases/latest).

ArDiRec is publicly available as a manual COMTRADE disturbance-analysis workstation. The initial Stable scope includes time signals, digital events, synchronized cursors, one-cycle RMS, phasors, harmonics, impedance locus, value table and a compact multi-window interface.

## Engineering reliability

The project maintains automated parser/calculation tests, regression fixtures, rendering and interaction checks, large-record benchmarks, CodeQL scanning, and packaging smoke tests. Windows packaging exercises install, launch and uninstall; Linux packaging exercises AppImage startup and Debian/ZIP assembly.

These checks do not substitute for field acceptance on every COMTRADE revision, relay vendor or local workstation environment. Report reproducible issues using [GitHub Issues](https://github.com/masarray/ardirec/issues).

## Product direction

Development prioritizes broad record compatibility, trustworthy numerical results, clear diagnostics, fast interaction and maintainable architecture. Additional analysis and export workflows remain subject to engineering validation; roadmap targets are not claims about shipped features.
