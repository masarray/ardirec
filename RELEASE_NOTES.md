# ArDiRec v0.2.0 — Stable release notes

**Published:** 3 November 2026  
**Platforms:** Windows 10/11 x64 and Linux x86_64

ArDiRec is an open-source desktop application for hands-on analysis of COMTRADE disturbance recordings.

## Highlights

- Inspect synchronized voltage, current, other analog channels, and digital event tracks in one timeline.
- Measure trigger-relative timing using two cursors, signal values and cursor differences.
- Review instantaneous waveforms, one-cycle RMS, phasors, harmonics, impedance trajectories and the value table.
- Display supported protection zones from RIO/XRIO data with explicit limitations for unsupported proprietary constructs.
- Use a compact multi-window workspace with responsive pan/zoom and performance-oriented rendering.

## Install

Download the appropriate ZIP from [v0.2.0](https://github.com/masarray/ardirec/releases/tag/v0.2.0). The Windows archive contains a per-user installer. The Linux archive contains a Debian package and an AppImage. Check the accompanying SHA-256 checksums before installation.

## Scope and limitations

This is a Stable distribution of the **manual analysis** workflow, not a guarantee of exhaustive COMTRADE/vendor compatibility or a certified fault-location system. Unsigned Windows executables may trigger SmartScreen. To report issues, use the [issue tracker](https://github.com/masarray/ardirec/issues), and avoid posting confidential field recordings.

See [Getting started](docs/GETTING_STARTED.md), [Compatibility](docs/COMTRADE_COMPATIBILITY.md), and [Changelog](CHANGELOG.md).
