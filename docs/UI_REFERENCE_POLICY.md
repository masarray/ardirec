# UI reference policy

ardirec intentionally preserves familiar disturbance-analysis workflow concepts while maintaining its own visual identity.

Allowed references:
- workflow order and engineering interaction patterns;
- common diagram types and measurement semantics;
- standard electrical phase colors and protection terminology.

Not copied:
- proprietary icons or visual assets;
- pixel-identical layouts;
- vendor-specific branding or trade dress.

The design goal is immediate usability for engineers familiar with legacy fault-record tools, with a compact modern industrial interface.
