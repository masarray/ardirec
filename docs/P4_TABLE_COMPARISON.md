# Table parity+ design

SIGRA's table is a strong benchmark for compact point-in-time engineering reading. ardirec P4 keeps the useful density but extends the workflow with:

- one shared snap-capable cursor;
- simultaneous Instant, RMS and H1 quantities;
- THD and selected harmonic ratios in the same row;
- scope and sort controls;
- highest-THD / highest-RMS summary strip;
- Primary/Secondary representation applied globally;
- virtualized rows and cached one-cycle snapshots.

The intent is capability/workflow familiarity without copying vendor visual assets or trade dress.
