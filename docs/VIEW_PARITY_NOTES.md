# View parity notes

The current ardirec view model follows the familiar disturbance-analysis workflow used by established tools without copying their visual design.

- Time Signals: shared timebase, analog/digital stack, dual measurement cursors, instantaneous/RMS display.
- Phasor: fundamental vectors at the selected cursor time.
- Locus: complex trajectory in the R-X plane.
- Harmonics: harmonic RMS bars and percent of fundamental.
- Table: synchronized cursor values.

Future parity gates add symmetrical components, power/frequency, calculated quantities, RIO/XRIO, record combination and fault analysis.
