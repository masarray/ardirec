# Roadmap

## G0 — Foundation (current)
Repository quality, C++ parser/reference DAT path, CLI, tests, Qt Quick shell and QSG renderer skeleton.

## G1 — Real Viewer
Real samples on GPU, packed digital tracks, shared timebase, pan/zoom, dual cursors, memory mapping/lazy decode and min/max LOD.

## G2 — Compatibility Lab
1991/1999/2001/2013, all required DAT formats, CFF, sample-rate transitions, missing data, skew/time metadata, record-health diagnostics, torture suite.

## G3 — Electrical Core
RMS, phasor, sequences, frequency context, P/Q/S/PF with explainable calculation windows.

## G4 — Analysis Views
Vector, R-X/locus, harmonics/spectrum and value table synchronized to global investigation context.

## G5 — Professional Workflow
Formula engine, calculated signals, RIO/XRIO, device profiles, workspace persistence, export.

## G6 — Viewer 1.0
Compatibility, calculation and performance release gates. Manual investigation parity is considered complete.

## G7 — Multi-record
Combine and synchronize records, source offsets and alignment evidence.

## G8 — Fault Analysis
Fault inception/type, breaker clearing, sequence timeline and validated fault-location methods.

## G9 — Protection Intelligence
Deterministic investigation assistant that explains measured/calculated evidence and separates it from heuristic suggestions.
