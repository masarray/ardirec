# Research Notes and Reference Projects

These references inform capability targets, interoperability risks and future validation. Their licenses and code must be reviewed before any reuse.

## Commercial capability benchmarks

- Siemens SIGRA — time signals, synchronized cursors, calculated quantities, vector/locus/harmonics/table and multi-record workflows.
- OMICRON TransView — time, vector, locus, harmonics and table workflow; XRIO-based distance-zone context.
- SEL SynchroWAVe Event — event analysis, reusable displays and custom calculations.

## Open-source references

- `dparrini/python-comtrade` (MIT) — broad revision/format coverage and useful redistributable sample fixtures.
- `power-waveform/comtrade-io` (MIT) — recent multi-file model, auto-location, CFF and equipment-oriented metadata ideas.
- `GridProtectionAlliance/openXDA` (MIT) — future reference for automated disturbance analytics and fault-location research after Viewer 1.0.
- `ispirata/comtrade-plot` (GPL-3.0, archived) — historical Qt/QCustomPlot viewer reference; not used as the rendering foundation.

## Research policy

- Standards are normative.
- MIT projects may be studied/reused only with attribution and an explicit dependency/reuse decision.
- GPL-compatible code still requires provenance documentation.
- Commercial software is black-box benchmarking only.
