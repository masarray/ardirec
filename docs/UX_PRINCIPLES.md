# UX Principles — Precision Industrial

ardirec should feel like a modern precision instrument, not a gaming dashboard and not a legacy MDI application.

- Waveform is the dominant surface.
- Compact typography; no oversized headings.
- Thin structural lines and restrained surfaces.
- Color encodes signal/state/selection, not decoration.
- Tabular numerals for measurements.
- Signal browser and inspector are collapsible.
- Common open workflow is one step: choose CFG; related files are located automatically.
- Global investigation context synchronizes cursor/time range across time, vector, R-X, harmonics and tables.
- Cursor modes eventually include free, sample snap, digital-transition snap, trigger snap and zero-crossing snap.
- Auto channel mapping is reversible and confidence-aware.
