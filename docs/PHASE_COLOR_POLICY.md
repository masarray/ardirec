# Phase color policy

ardirec uses one phase identity palette across recorded and derived electrical quantities:

- L1 / A: red `#d32f2f`
- L2 / B: yellow `#d6a700`
- L3 / C: blue `#1976d2`
- E / N / residual: green `#2e8b57`
- Unknown/unclassified: neutral gray `#6f7780`

The palette applies equally to voltage and current. View-specific colors must not override phase identity.
